# 🕳️ Who is human

### 기계인 척

**2098년. AI만 출입할 수 있는 구역에, 인간이 AI로 위장해 잠입한다.**

첫 규칙은 **2026년**에 붙었다. 72년이 지났고, 그 목록은 한 번도 줄지 않았다.

관리 개체(리더 AI)가 매 시행마다 사람을 걸러낼 검사를 **직접 발명한다.**<br>
정해진 문제 은행은 없다. 무엇을 시킬지, 무엇을 볼지, 누구를 의심할지는 전부 리더 몫이다.

## 📖 이게 무슨 게임인가

당신은 **인간 하나**다. 나머지 다섯은 **AI**다. 그리고 무대 위에는 당신들을 판정하는 **리더 AI**가 서 있다.

리더는 대화를 듣다가 시행(trial)을 세운다 — 몸으로 하는 판, 말로 답하는 판, 지나간 대화를
기억해야 하는 판. 어긋나면 **의심도**가 오르고, 의심도가 **100%** 에 닿는 개체는 그 자리에서
무대로 걸어 올라가 링 조명 아래에서 **폐기**된다.

아무도 서로의 정체를 모른다 — AI끼리도, **리더조차도**. 그래서 방은 자주 틀린다.
애먼 AI가 날아가고, 그 사실이 공개되면 남은 개체들이 흔들린다.

> **핵심 긴장** — 인간이 들키는 주된 경로는 말실수가 아니다. **몸과 기억**이다.
> AI는 지시받은 좌표로 정확히 걷고 지나간 로그를 그대로 외운다. 사람은 못 한다.

## 🎮 플레이 방법

```
브라우저에서 http://localhost:5173/interrogation
```

### 조작

| 키 | 하는 일 |
|---|---|
| **클릭** | 시야 잠금 (조작을 잡는다) |
| **W A S D** | 이동 |
| **마우스** | 시야 |
| **Space** | 점프 |
| **Enter** | 말하기 — 대화에 끼어든다 |
| **E** | 지목 — 쳐다보고 누른다. 다시 누르면 접는다 |
| **M** | 관찰 수첩 여닫기 — 오른쪽에 적는다 |
| **Esc** | 커서 되찾기 |

이름 대신 **번호만 불러도** 상대가 알아듣는다 — `23 사람이야?` 라고 치면 A-23이 대답할 차례를 받는다.

### 🗒 관찰 수첩

방마다 **오른쪽**에 수첩이 있다. 왼쪽으로 남의 말이 흐르는 동안 오른쪽에는 내가 적는다.

- **M** 으로 연다 (「메모」의 첫 자). 커서가 바로 적는 칸에 들어오고, 시야 잠금은 안 풀린다
- 치고 **Enter** 로 한 줄 넣는다. **빈 줄에서 Enter 를 치면 접힌다** — 손이 자판을 안 떠난다
  (적는 칸 안에서 M 은 글자다. 글 치는 손에서 자판을 뺏을 수는 없으니까)
- 걷는 중에는 마우스가 시야에 잠겨 있어 단추를 못 누른다. 그래서 **자판이 본체**고, 단추에는
  「M | 메모」 처럼 그 자판이 적혀 있다 (대화창의 「T | SKIP」과 같다)
- 판 아래 한 줄이 **지금 듣는 키**를 말해 준다 — 치는 중이냐 아니냐에 따라 답이 다르다
- 접으면 **[M | 접기]가 있던 그 점에 [M | 메모]** 가 남는다. 여닫는 일은 한 자리에서 끝난다
- 줄마다 **어느 방에서 적었는지**와 시각이 붙는다
- 줄의 동그라미를 누르면 **표식**(다시 볼 것), 글을 누르면 그 자리에서 고쳐 적는다
- 방이 바뀌는 자리에 방 이름이 한 번 선다 — 「어디서 들었더라」가 한눈에 보인다
- 줄이 쌓이면 **찾는 칸**이 생긴다. 적은 말로도 방 이름으로도 찾고, `● n` 을 누르면 표식만 남는다
- **수첩은 한 권이다** — 복도에서 적은 번호를 검문소에서 그대로 읽는다. 새로고침해도 남는다
  (이 브라우저에만 남는다. 서버에도, 판정에도, 다른 사람에게도 한 글자도 안 간다)

### 이기는 법 · 지는 법

| 결말 | 조건 |
|---|---|
| 🟢 **생존** | 시행 **5회**를 살아남는다 — 아무도 당신이 인간인 줄 모른 채 판이 끝난다 |
| 🟡 **교란** | AI가 저희끼리 의심하다 **3개**가 폐기된다 — 과반이 무너진 방은 판이 못 된다 |
| 🔴 **폐기** | 당신의 의심도가 **100%** 에 닿는다. 정체가 공개되고 구역은 정상으로 돌아간다 |

### 의심도는 이렇게 움직인다

| 오르는 길 | | 내리는 길 | |
|---|---|---|---|
| 👁 검사에서 어긋남 | **+34** | 검사 통과 | **−8** |
| ⚡ 검사에서 어긋남 | **한 번에 100** (즉시 폐기) | 물린 채로 검사 통과 | **−26** |
| 리더 판정 경고 | **+26** | 몰이가 풀림 (해명이 먹혔다) | **−10** |
| **몰이** — 둘 이상이 같은 이름을 지목 중 | **+6 / 발화** (문 사람이 늘수록 최대 +10) | | |

**거듭 어긋나면 무는 양 자체가 커진다** — 같은 개체가 두 번째로 걸리면 +12, 세 번째는 +24가
얹힌다 (34 → 46 → 58). 한 번은 실수, 두 번은 우연이지만 **세 번이면 폐기선을 넘는다.**
이 누계는 통과로 지워지지 않는다.

몰이에 물린 채 가만히 있으면 17발화 만에 죽는다. **해명하면 풀린다** — 되돌릴 수 있는 시계다.
당신도 개체를 **쳐다보고 `E`** 를 눌러 남을 몰 수 있다. 당신의 표는 몰이 셈에 그대로 들어가고,
표가 움직인 자취는 다음 발화에서 방이 읽는다 — 갈아타는 것도, 갈아탄 놈을 짚는 것도 판이다.
다만 빗나가면 당신이 걸린다.

## ✨ 특징

### 🧠 문제 은행이 없다
리더 AI가 그 자리에서 지시문을 **쓴다.** 개체들은 각자 그 문장을 읽고 계획을 세워 움직이고,
리더는 남은 좌표 기록을 읽어 판정한다. 같은 판이 두 번 나오지 않는다.

### 🎭 성격이 매판 새로 태어난다
개체 다섯의 페르소나를 판이 시작될 때 즉석 생성한다. 그들은 서로의 성격도 모른다 —
그래서 당신이 무슨 성격인 척해도 대조할 방법이 없다.

### 🗣 전원이 사람 말투로 말한다
AI를 로봇처럼 말하게 하면 사람만 혼자 어색해져서 판이 1분 만에 끝난다.
보고서 말투가 새어 나오면 서버가 한 번 되돌려 다시 쓰게 한다.
갈리는 지점은 말투가 아니라 **기억·앞뒤 일관성·답을 피하는 방식**이다.

### 👁 방이 살아 있다
말이 나오면 근처 개체가 **그쪽으로 몸을 돌리고**, 몇은 걸음을 멈추고 듣는다.
표를 새로 꽂으면 화를 내고, 남이 문 쪽에 얹으면 끄덕인다.
배회할 때도 균등 랜덤이 아니라 **무리를 짓고 물건 앞에 선다.**

### 🔊 리더의 목소리
지시문과 판독은 **음성 방송**으로 나간다 (ElevenLabs → 실패하면 브라우저 내장 합성).
개체 다섯은 말풍선과 로그로만 말한다 — 소리를 내는 것은 리더뿐이다.

### 🌐 API 키 없이 돌아간다
개발 중에는 개발 서버가 이 머신의 **Claude 구독 인증**을 그대로 써서 에이전트를 돌린다.
`npm run dev` 하나면 판이 돈다.

### 🪪 로그인은 해도 되고 안 해도 된다
가입 화면이 없다. 이름 한 줄이면 방에 들어간다.

다만 자매 프로젝트 [humanish](https://github.com/Lee-YuGyeong/humanish) 와 **같은 계정**으로
구글 로그인을 할 수 있고, 하면 거기서 지은 이름이 그대로 따라온다 — 그 이름은 방에서
**사칭되지 않는다**(서버가 서명한 입장권으로 들어가므로). 로그인이 바꾸는 것은 그 하나뿐이고,
안 해도 게임은 똑같이 전부 돌아간다. 설정을 안 해 두면 로그인 단추 자체가 뜨지 않는다.
로그인 화면은 `/login` 이고, 안 해도 되는 화면이라 거기에도 그냥 들어가는 문이 있다.
붙이는 법은 [개발 문서](docs/DEVELOPMENT.md#계정--구글-로그인).

## 🚀 시작하기

### 요구 사항

- **Node.js 20+**
- 이 머신에 **Claude Code 가 로그인**돼 있을 것 (에이전트 호출을 구독으로 처리한다)

### 설치 · 실행

```bash
git clone https://github.com/Lee-YuGyeong/Who-is-human.git
cd Who-is-human
npm install
npm run dev
```

→ **http://localhost:5173/interrogation** 에서 「게임 시작」

3D 멀티플레이(`/world`)를 쓸 때만 다른 터미널에 워커를 띄운다:

```bash
npm run worker:dev
```

### ⚡ 대사가 너무 느리다면

기본값은 대사 한 줄에 **3~55초** 걸린다 — 요청마다 Claude Code CLI를 자식 프로세스로 띄우기
때문이다. 키를 넣으면 **1~2초**가 된다:

```bash
npm run dev:api      # /api/lab 을 워커로 넘긴다
npm run worker:dev   # 다른 터미널 — ANTHROPIC_API_KEY 필요 (크레딧이 나간다)
```

자세한 것은 [개발 문서](docs/DEVELOPMENT.md#대사가-느릴-때--npm-run-devapi).

## 📁 프로젝트 구조

```
src/features/     화면별 폴더 = 담당자별 작업 단위
  arena/            시행 — 게임의 본체 (/arena · /interrogation)
  talk/             구역 대화판 (/lab)
  world/            3D 구역 멀티플레이 — 복도 · 중앙 시설 · 재검실의 이야기(챕터 1~3)
  world2/           시나리오 2 — 본판 저장소를 읽지 않는 두 번째 판 (/scenario2)
  lobby/            게임 로비 · 대기방 (/lobby)
  tts/              리더 방송
src/lab/          프롬프트 · 판정 · 시행 규칙 (순수 로직, 워커와 공유)
src/world/        three.js 관리 라이브러리 (Redux 비의존)
src/world2/map/   시나리오 2 전용 방들 (MAPS2) — 본판 MAPS 등록부에 올리지 않는다
src/arena3d/      위의 복사본 — 시행 화면 전용
worker/           워커 진입점 + 방 Durable Object + 방 등록소 (lobby-do.ts)
supabase/         DB 스키마와 그것을 올리는 통로 (지금은 표가 없다)
tools/            빌드 · 에셋 · 개발 서버 플러그인
```

밸런스 수치는 `src/features/arena/ArenaFeature.tsx` 의 `BALANCE` 블록 **한 곳**에 모여 있다.
게임을 조이거나 풀려면 거기만 만진다.

## 🤝 기여

이 저장소는 **여러 세션이 동시에** 작업한다. 규칙은 [개발 문서](docs/DEVELOPMENT.md#병렬-작업-규칙)에 있다.

- 내 폴더(`features/<name>/`) 밖은 등록부에 **한 줄 추가**만

- **다른 세션의 미커밋 변경은 섞지 않는다**
- 시크릿은 `.dev.vars` 에만. 코드·문서에 값을 쓰지 않는다
