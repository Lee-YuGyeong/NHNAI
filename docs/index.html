PDF 로 내보내기

세 문서는 외부 리소스 없이 파일 하나로 렌더링되고, A4 인쇄 규칙(@page)이 들어 있다. 두 가지 방법 중 하나로 PDF 를 만든다.

  1. 브라우저 인쇄 — 문서를 Chrome 으로 열고 ⌘P → 대상 「PDF 로 저장」 → 용지 A4 · 여백 기본 · 「배경 그래픽」 켜기. 표지·목차·큰 절마다 쪽이 나뉜다.
  2. 명령줄(Chrome 헤드리스) — 저장소 루트에서: 
    CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
for f in game-manual build-guide tech-spec; do
  "$CHROME" --headless=new --disable-gpu --no-pdf-header-footer \
    --print-to-pdf="docs/$f.pdf" "file://$PWD/docs/$f.html"
done

스크린샷은 docs/img/ 에 PNG 로 들어 있다. 화면이 바뀌면 같은 이름으로 다시 찍어 넣으면 세 문서에 그대로 반영된다.

문서 관리

  • 세 문서의 수치는 코드의 상수(src/world/mp/game-protocol.ts 등)를 그대로 옮긴 것이다. 규칙을 바꾸면 문서의 표도 같이 고친다.
  • 범위: 인트로 → 로그인 → 방 목록/대기방 → 검문실 판. 실험용 페이지(3D 월드 · 창고 · 중앙 시설 · 재검실 등)는 문서 범위 밖이다.
  • 같은 폴더의 DEVELOPMENT.md · SUSPICION.md · SPEECH.md · VOICE.md 는 개발 중 메모로, 기술설명서가 그 내용을 정리해 담는다.
